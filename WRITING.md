# How the writing gets done

The code in this repo is scaffolded. The prose is not, on purpose.

## The loop

1. You draft an essay or a reflection in one of your two registers:
   - **RAW**: unfiltered, first pass, say the true thing before it is tidy
   - **STRUCTURED**: the same content shaped for a reader, still your voice
2. You hand the draft over for review only. Review means: does it hold, is it
   yours, does it flatten anything, where is it hand-wavy. Not a rewrite.
3. You revise. Repeat until it is done.

## Rules

- No dashes. Commas, colons, parentheses, or split the sentence.
- Keep it true before you keep it polished. A rough true line beats a smooth
  vague one.
- Every claim about the atonement gets checked against the governing test in the
  README: does this conserve the cost or reduce it.
- Scripture references get quoted, not paraphrased into a stronger claim than the
  text makes.
