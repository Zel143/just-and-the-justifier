# part2-metaphor

Four small notebooks. ML as the metaphor vehicle, held to the conserve-versus-
reduce test from Part 1.

| File | Needs libs | One line |
| --- | --- | --- |
| `a_the_loss_is_real.py` | numpy, matplotlib | the loss does not reach zero because you want it to |
| `b_cost_sensitive_learning.py` | numpy, scikit-learn | who gets charged for each kind of mistake is a moral choice |
| `c_the_two_model_ledger.py` | none (stdlib) | the centerpiece: cost fully paid, fully transferred |
| `d_calibration.py` | numpy, scikit-learn, matplotlib | a merciful verdict can still be a true one; sets up Part 3 |

Each `.py` is a `# %%` cell script. Run with `python <file>` from the repo root,
or open as a notebook in VS Code. Figures land in `figures/`.

Every notebook has a **Reflection** cell near the top marked `TODO`. That prose is
yours, RAW register, per `../WRITING.md`.
